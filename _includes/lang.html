{%- comment -%} Sets `lang`, `c` (header/footer strings), `en_url` and `zh_url` for the current page. Landing pages say `lang:` in their front matter; the legal pages are Markdown that must stay untouched, so they are told apart by path. Layouts render separately, so each layout that needs these includes this. {%- endcomment -%} {%- if page.lang -%} {%- assign lang = page.lang -%} {%- elsif page.url contains '/zh/' -%} {%- assign lang = 'zh' -%} {%- else -%} {%- assign lang = 'en' -%} {%- endif -%} {%- assign c = site.data.chrome[lang] -%} {%- if page.url contains '404' -%} {%- assign en_url = '/' -%} {%- assign zh_url = '/zh/' -%} {%- elsif lang == 'zh' -%} {%- assign zh_url = page.url -%} {%- assign en_url = page.url | remove_first: '/zh' -%} {%- else -%} {%- assign en_url = page.url -%} {%- assign zh_url = '/zh' | append: page.url -%} {%- endif -%}
